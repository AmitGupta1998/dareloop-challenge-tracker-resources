# DareLoop - Challenge Tracking & Accountability Platform

DareLoop helps people stay accountable by creating challenges, tracking progress, and sharing achievements.

## Features

- Create personal challenges
- Join public challenges
- Track streaks
- Earn points
- Community accountability
